# desafio-dio-calculadora-rankeada
Desafio destinado a colocar em prática conceitos básicos de programação em JS parte 2

---
## Recursos utilizados
  - condicionais
  - operadores lógicos
  - variáveis e constantes
  - funções

---
> [!TIP]
> Acesse **desafio-dio-calculadora-rankeada/script.js** para clonar o arquivo;
---
## Passo a Passo

- Copie o código e rode na sua IDE para reutilizar o código;
- Para mudar a saída do console, mude os parâmetros <ins>(vitorias, derrotas)</ins> com o primeiro valor sendo o número de vitórias, e o segundo, de derrotas;
- Para rodar o projeto, digite no terminal o seguinte código:
```
node script.js
```
